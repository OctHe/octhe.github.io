## iw

iw is a configuration tool for mac80211 in Linux kernel with netlink
Part of the code tree of `iw.c` in iw is

- main
    - version
    - nl80211_init
        - nl_socket_alloc
        - nl_socket_free
        - nl_socket_set_buffer_size
    - usage
        - __usage_cmd
        - usage_options
    - __handle_cmd
        - error_handler
        - finish_handler
        - ack_handler
        - register_handler
        - valid_handler
        - phy_lookup
    - phy_lookup
    - nl80211_cleanup
- TOPLEVEL
    - print_help
- handle_cmd
    - __handle_cmd
- usage_cmd
    - __usage_cmd

## Proxy

Auto detect proxy with `nc` and connect to it

    if nc -z $<srv_ip> $<proxy_port>; then
        git config --global http.proxy "http://$<srv_ip>:$<proxy_port>"
        git config --global https.proxy "https://$<srv_ip>:$<proxy_port>"

    elif nc -z $<local_ip> $<proxy_port>; then
        git config --global http.proxy "http://$<local_ip>:$<proxy_port>"
        git config --global https.proxy "https://$<local_ip>:$<proxy_port>"

    else
        git config --global --unset http.proxy 
        git config --global --unset https.proxy
    fi

## Clash

clash is a tunnel in Go.

### Installation

The package can be downloaded from [Github release](https://github.com/Dreamacro/clash/releases).
It also can be downloaded in command line.
As an example

`wget https://github.com/Dreamacro/clash/releases/download/v1.18.0/clash-linux-amd64-v1.18.0.gz`

### Basic Usage

If clash is run in the user space, copy the `config.yaml` file to `~/.config/clash/` directory and run

`clash`

Clash will download the `Country.mmdb` file itselef and load the configuration in `~/.config/clash/`.

### Autostart

    [WARING] OpenSUSE may not support clash for now since the Github page of clash is closed.

Systemd supports auto-start clash after opening the system.
In openSUSE, the download version of clash has a systemd service with `/lib/system/system/clash.service` to support the auto-start process.
This service is based on systemd, so it works for openSUSE and other distributions that uses systemd as the init process.
Different from manually run clash, the systemd will load the configuration in the directory `/etc/clash/` by default.
So move the configuration file and mmdb file in the above directory by

`sudo mv /path/to/config/file /etc/clash/`
`sudo mv /path/to/Country.mmdb /etc/clash`

Then, enable and start clash service

`systemclt enable clash`
`systemclt start clash`

The final process is to config the system-level network setting or program-level network setting to use the clash service.

### Clash for LAN
 
Clash can support connection from devices in the local area network (LAN).
To enable it, just edit the config.yaml file and set the `allow-lan` to `true`.
